# Internal campaign archive

These documents preserve Camelid's historical recon, conductor, campaign, and
decision records. They are implementation history, not contributor onboarding,
current product documentation, or support contracts.

For current information, use:

- [`README.md`](../../../README.md) for the project overview and quick start;
- [`CONTRIBUTING.md`](../../../CONTRIBUTING.md) for contribution guidance;
- [`COMPATIBILITY.md`](../../../COMPATIBILITY.md) for authoritative support boundaries;
- [`STATUS.md`](../../reference/STATUS.md) for the current evidence snapshot; and
- [`DOCS.md`](../../../DOCS.md) for the public documentation index.

Campaign files remain in this directory so older evidence bundles and design
notes can retain a stable, reviewable provenance trail without crowding the
repository root.
